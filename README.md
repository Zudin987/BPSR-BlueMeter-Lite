# BlueMeter Lite

Android combat meter for **Blue Protocol: Star Resonance**. Shows DPS, healing, and damage received over the game.

**Website:** https://zudin987.github.io/projects/bluemeter/

## Use

1. Download the latest APK from [Releases](https://github.com/Zudin987/BPSR-BlueMeter-Lite/releases/latest).
2. Most recent phones use **arm64-v8a**.
3. Open BlueMeter Lite → **Start DPS Meter**.
4. Allow **Display over other apps** and approve Android's VPN prompt.
5. Open BPSR and fight.

The Android VPN is used for **local packet capture**. It is not a remote VPN service. Combat data stays on your device.

Game/protocol updates may require a BlueMeter update.
