# Recommended repository settings

## Disable unsupported communication features

Because routine feedback and diagnosis are not planned:

1. Open **Settings**
2. Open **General**
3. Under **Features**, uncheck:
   - Issues
   - Projects
   - Discussions, when enabled

Pull requests can remain available because GitHub does not provide the same simple repository-level switch for public forks and contributions.

## Files to delete

Delete these obsolete files from the repository:

```text
VALIDATION.md
CONTRIBUTING.md
UPDATE-INSTRUCTIONS.md
```

`VALIDATION.md` incorrectly says the app was not built or phone-tested.  
`CONTRIBUTING.md` invites feedback and bug reports that are not planned.  
`UPDATE-INSTRUCTIONS.md` is a development handoff file, not end-user documentation.
