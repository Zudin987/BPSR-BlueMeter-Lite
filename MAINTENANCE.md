# Maintenance Status

BlueMeter Lite is feature-complete and provided as-is.

Routine support, diagnosis, feature requests and active protocol maintenance are not planned. The repository remains public so users can inspect the source and build the app.

A future Blue Protocol: Star Resonance update can change the network protocol and prevent the meter from working. There is no guarantee that compatibility will be restored.

The author may publish an occasional critical compatibility or security update at their own discretion.
