# BlueMeter Lite 1.0.0

The first stable release of BlueMeter Lite: a lightweight Android DPS overlay for Blue Protocol: Star Resonance.

## Highlights

- Runs directly on Android — no PC required
- Compact and Expanded overlay modes
- Total damage, DPS and contribution percentage
- Profession/specialization, Ability Score and Illusion-Breaking Strength
- Local-player star and row highlight
- One-column scrollable ranking
- Movable and resizable overlay
- BPSR-only local VPN allow-list

## Installation

Download the APK marked `arm64-v8a` for most modern Android phones.

After installation:

1. grant Display over other apps
2. tap Start DPS Meter
3. approve Android's VPN request
4. launch BPSR

## Supported clients

- HaoPlay SEA
- A Plus Japan / Global
- Taiwan / Hong Kong / Macau
- X.D. regional client

## Notes

- Android displays a VPN indicator while the local capture service is active.
- This is an unofficial community project.
- Game protocol updates can require a BlueMeter Lite update.
